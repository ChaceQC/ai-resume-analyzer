# 招聘行情试点数据

这些样本来自腾讯、网易、美团的官网公开招聘接口，以及清单所列国际企业的 Greenhouse 公开招聘接口。采集日期为 **2026-11-05**，具体时间、来源、各企业原始职位数量及筛选后覆盖范围见 [snapshot.manifest.json](snapshot.manifest.json)。

- `snapshot.json.gz`：完整的筛选样本，包含职位、公司、地点、更新时间、要求原句、原文指纹及职位链接。
- `snapshot.manifest.json`：便于审阅的统计、采集口径、来源链接和快照标识。
- 只保留近60天更新且能提取能力要求的职位，每家公司/岗位族/职级/工作地点最多25条；更新日期不是首次发布日期。
- 来源明确提供的实习、校招类型优先用于职业阶段分类；其他职位按标题推断。
- 样本覆盖国内头部科技企业及部分国际企业的职位，不能作为全市场、城市就业供需、实际薪资或候选人排名的统计。
- 多地点职位可同时匹配多个城市；地区样本数量不可直接相加。
- 职位页面可能在采集后更新；报告展示当次采集的文本片段及链接。

更新方式：

```bash
.venv/bin/python update_market.py
# 有本地代理时：
.venv/bin/python update_market.py --proxy http://127.0.0.1:7897
```

更新工具保留采集来源，重新进行筛选、去重和指纹计算；分析请求只读取本地快照。没有足够同类企业和职位、指定地区无覆盖或快照过期时不生成行情分。

默认采集国内与国际来源；可通过 `--sources domestic` 或 `--sources international` 只采集对应来源。网页默认中国地区，在开始分析前显示当前筛选范围的样本数量，并支持明确切换城市。
